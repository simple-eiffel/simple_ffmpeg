Overview

simple_ffmpeg provides high-level Eiffel bindings to FFmpeg's libav* C libraries. It enables video/audio encoding, decoding, transcoding, and metadata extraction with a clean, contract-driven API.

Part of the Simple Eiffel ecosystem.

Quick Start

Installation

  1. Install FFmpeg development libraries: 
    # Windows (vcpkg)
vcpkg install ffmpeg:x64-windows

# Linux
sudo apt install libavcodec-dev libavformat-dev libavutil-dev libswscale-dev

# macOS
brew install ffmpeg
  2. Set environment variables: 
    export FFMPEG_INCLUDE=/path/to/ffmpeg/include
export FFMPEG_LIB=/path/to/ffmpeg/lib
export SIMPLE_EIFFEL=/path/to/prod
  3. Add to your ECF file: 
    <library name="simple_ffmpeg" location="$SIMPLE_EIFFEL/simple_ffmpeg/simple_ffmpeg.ecf"/>

Basic Usage

local
    ffmpeg: SIMPLE_FFMPEG
do
    create ffmpeg.make

    -- Get media info
    if attached ffmpeg.probe ("video.mp4") as info then
        print ("Duration: " + info.duration.out + " seconds%N")
        print ("Resolution: " + info.resolution_string + "%N")
    end

    -- Simple transcode
    if ffmpeg.transcode ("input.avi", "output.mp4") then
        print ("Done%N")
    end
end

Transcoding

With Options

local
    ffmpeg: SIMPLE_FFMPEG
    options: FFMPEG_OPTIONS
do
    create ffmpeg.make
    create options.make

    options := options
        .set_video_codec ("libx265")
        .set_resolution (1280, 720)
        .set_video_bitrate (2_000_000)
        .set_audio_codec ("aac")
        .set_audio_bitrate (128_000)

    ffmpeg.transcode_with_options ("input.mov", "output.mp4", options)
end

Fluent Transcoder

local
    trans: FFMPEG_TRANSCODER
do
    create trans.make ("input.mov", "output.mp4")
    trans
        .set_video_codec ("libx264")
        .set_video_bitrate (2_000_000)
        .set_resolution (1920, 1080)
        .set_audio_codec ("aac")
        .set_audio_bitrate (128_000)

    if trans.run then
        print ("Complete%N")
    end
end

Presets

local
    options: FFMPEG_OPTIONS
do
    create options.make

    -- Web-optimized (720p)
    options := options.preset_web

    -- Quality-focused
    options := options.preset_quality

    -- Stream copy (no re-encoding)
    options := options.copy_video.copy_audio
end

Frame-by-Frame Decoding

local
    ffmpeg: SIMPLE_FFMPEG
do
    create ffmpeg.make
    if attached ffmpeg.open_input ("video.mp4") as decoder then
        from until not decoder.read_video_frame loop
            if attached decoder.current_video_frame as frame then
                print ("Frame " + decoder.frame_number.out + "%N")
                frame.save_as_jpeg ("frame.jpg", 90)
            end
        end
        decoder.close
    end
end

Encoding Video

local
    ffmpeg: SIMPLE_FFMPEG
    options: FFMPEG_ENCODER_OPTIONS
do
    create ffmpeg.make
    create options.make (1920, 1080, 30.0)  -- 1080p @ 30fps

    if attached ffmpeg.create_encoder ("output.mp4", options) as encoder then
        from i := 1 until i > 300 loop
            create frame.make_rgb (1920, 1080)
            -- Fill frame with pixel data...
            encoder.write_video_frame (frame)
            i := i + 1
        end
        encoder.finalize
        encoder.close
    end
end

API Reference

SIMPLE_FFMPEG (Facade)

Method Description
probe (file) Get media file info
transcode (in, out) Convert with auto settings
transcode_with_options (in, out, opts) Convert with explicit options
extract_audio (video, audio) Extract audio track
extract_frame (video, time, out) Extract frame at timestamp
resize_video (in, out, w, h) Resize video
open_input (file) Open for frame-by-frame decoding
create_encoder (file, opts) Create encoder for output

FFMPEG_OPTIONS (Builder)

Method Description
set_video_codec (codec) libx264, libx265, libvpx-vp9, copy
set_video_bitrate (bps) Video bitrate in bits/second
set_resolution (w, h) Output width and height
set_frame_rate (fps) Output frame rate
set_audio_codec (codec) aac, libmp3lame, flac, copy
set_audio_bitrate (bps) Audio bitrate in bits/second
copy_video Stream copy video (no re-encoding)
copy_audio Stream copy audio (no re-encoding)
preset_web Web-optimized settings (720p)

FFMPEG_MEDIA_INFO

Attribute Type Description
duration REAL_64 Duration in seconds
video_width INTEGER Video width in pixels
video_height INTEGER Video height in pixels
video_codec STRING_32 Video codec name
audio_codec STRING_32 Audio codec name
audio_sample_rate INTEGER Sample rate in Hz
audio_channels INTEGER Number of channels

Supported Formats

Video Codecs
